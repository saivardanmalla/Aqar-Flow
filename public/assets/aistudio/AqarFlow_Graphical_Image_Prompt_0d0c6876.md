# AQARFLOW — Graphical Image Generation Prompt

Create a sleek, high-detail promotional hero composite for VIRELEO’s **AqarFlow** real estate platform, combining a public property marketplace, mobile experience, and admin dashboard in a polished navy, white, and green UI.

The scene features a twilight city-and-architecture backdrop, branded **“AqarFlow by VIRELEO”** messaging, property search and listing cards, a mobile **“Find Your Dream Property”** view, a KPI-rich operations dashboard, and a footer highlighting listings, CRM, scheduling, deal tracking, analytics, and secure scalability.

## Visual direction

- **Brand:** AqarFlow by VIRELEO
- **Product:** Real Estate ERP, CRM, and Property Marketplace
- **Color palette:** Deep navy, white, professional blue, and restrained green accents
- **Style:** Premium SaaS product presentation, realistic architectural photography, clean modern interface design
- **Composition:** Wide hero layout showing the public website on the left, an admin dashboard on the right, and a mobile interface prominently in the foreground
- **Backdrop:** Elegant twilight cityscape with contemporary luxury architecture

- AqarFlow navigation and branding
- Headline: “Find Your Dream Property”

- Featured property cards with imagery, prices, locations, and property details

### Admin workspace dashboard
- AqarFlow-branded sidebar and top navigation
- KPI cards for total properties, new leads, scheduled visits, and open deals
- Monthly inquiries chart
- Lead pipeline chart
- Recent activity panel
- Upcoming visits panel

### Mobile experience
- Responsive AqarFlow interface
- “Find Your Dream Property” headline
- Property search action
- Featured property preview

### Footer feature highlights
- Property Listings
- Lead Management CRM
- Visit Scheduling
- Deal Tracking
- Analytics & Reports
- Secure & Scalable
- VIRELEO brand signature with the tagline “Build • Innovate • Grow”
